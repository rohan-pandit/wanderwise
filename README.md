# Wanderwise

A travel-planning and booking-preparation concierge using AI-assisted interpretation and curation over a deterministic, testable planning engine.

This is a portfolio project. The travel domain is a vehicle — the actual point is demonstrating agentic AI product/engineering judgment: multi-agent orchestration with a clean deterministic/AI boundary, persistent state and memory, RAG, enforced guardrails, a real evaluation suite, and workflow-level observability with cost/latency/cache analysis.

Full specification, architecture decisions, and rationale live in [`PROJECT_BRIEF.md`](./PROJECT_BRIEF.md). Build history and session-by-session decisions are tracked in `BUILD_LOG.md`.

**Status:** early build — see `BUILD_LOG.md` for current progress.
